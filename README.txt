STUDENT MANAGEMENT SYSTEM - WEBSITE DEMO

HOW TO OPEN
1. Extract this ZIP file.
2. Open the folder.
3. Double-click index.html. It opens in Chrome or another browser.
4. Add a student using the form. Try Edit, Delete and Search.

IMPORTANT
This is a front-end demonstration prototype. It uses HTML, CSS and JavaScript.
Student records are saved in the browser's localStorage on that device/browser.
It is not yet connected to a Java Spring Boot backend or MySQL database.
Do not enter real or confidential student information.

HOW TO PUBLISH AND GET A SHAREABLE WEBSITE LINK
1. Open https://app.netlify.com/drop in a browser on your laptop.
2. Sign in or create a free Netlify account.
3. Extract this ZIP.
4. Drag the extracted student_management_website folder (the folder containing index.html)
   into the Netlify Drop upload area.
5. Wait for deployment. Netlify will show a public website URL.
6. Copy that URL and add it to your PowerPoint slide as the project demo link.

To make it a true Java Full Stack application later, add a Java Spring Boot REST API
and a MySQL database, then connect the form to those APIs.
